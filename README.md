# Autonomous Boat Setup Guide

A complete guide to building an autonomous surface vessel (USV) using the Cube Orange Plus flight controller, Blue Robotics T500 thrusters, and ArduRover firmware.

## What this guide covers

This guide walks through setting up a boat that can:
- Be driven manually with a long-range RC controller
- Hold position automatically using GPS
- Run autonomous waypoint missions

## What the build is

A skid-steer surface boat with:
- **Cube Orange Plus** flight controller
- **2× Blue Robotics T500** thrusters
- **2× Basic ESC 500** speed controllers
- **Here2 GPS/compass**
- **RFD900x** telemetry radio
- **FrSky R9M + R9 SX** long-range RC system
